# Linux: chmod, chown, права доступа и владелец файла

`chmod` (change mode) меняет права доступа к файлу или каталогу. `chown` (change owner) меняет владельца и, при указании, группу. Это разные операции: смена владельца сама по себе не выдаёт права rwx. `chgrp` меняет группу, `umask` ограничивает начальные права новых файлов.

`chmod 755 script.sh`: владелец rwx (чтение, запись, выполнение), группа и остальные r-x (чтение и выполнение). `chmod 644 report.txt`: владелец rw-, группа и остальные r--. Число 5 означает 4+1, то есть чтение И выполнение.

`r` = чтение, `w` = запись, `x` = выполнение; права задаются отдельно для владельца (u), группы (g) и остальных (o). В числовой записи r=4, w=2, x=1; значения складываются. `chmod 640 report.txt` даёт владельцу rw-, группе r--, остальным ---; `chmod u+x script.sh` добавляет владельцу выполнение. `chown alice:qa report.txt` задаёт владельца alice и группу qa; для смены владельца обычно нужны повышенные полномочия.

Для каталога r разрешает чтение списка имён, w — изменение записей, x — проход и доступ к объектам по имени. Для удаления файла важны права родительского каталога и sticky bit, а не только права самого файла. Не использовать `chmod 777` и рекурсивные изменения без понимания области действия.

При Permission denied: `id`, `ls -ld` для файла и родительских каталогов, `stat`; проверить пользователя процесса, ACL, read-only mount, SELinux/AppArmor. `sudo` повышает полномочия, но не объясняет первопричину.

Справочные материалы: GNU Coreutils, разделы chmod и chown. Команды здесь — учебные примеры, не запрос на выполнение.
