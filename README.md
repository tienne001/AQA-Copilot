# AQA Copilot

Локальный помощник QA/AQA для Windows: распознавание речи, ответы на технические вопросы, справочные карточки и код в читаемых блоках.

## Текущий снимок

Исходники актуальной сборки от 16 октября 2026 года. Backend, интерфейс и ресурсы собраны из последних проверенных версий; личная установка и данные пользователя сюда не копировались.

- Ответы в стиле краткой реплики на собеседовании.
- Gemma использует справочные карточки как опору и генерирует ответ сама; готовый ответ напрямую из карточки не выдаётся.
- Просьбы написать код распознаются явно и через постановку задачи: «нужно сделать алгоритм», «дан массив — убрать повторы». Уточнения используют предыдущую задачу.
- Для задач на код резервируется больше доступной истории. Размер контекста модели не увеличивался.
- Код с отступами, копированием и переключателем переноса строк; абзацы, списки, выделения и простые таблицы.
- Кнопка очистки контекста сохраняет прежнюю историю.
- Поддерживается пауза окончания речи до 5000 мс; в текущем профиле — 4000 мс.

Модель текущего профиля: локальный тег Ollama `gemma4:12b-it-qat`. ASR: Whisper large-v3, CUDA, int8_float16. Параметры профиля находятся в [config/settings.example.json](config/settings.example.json); путь к модели ASR нужно заменить на свой. В исходниках сохранены прежние значения по умолчанию для новой установки — профиль текущей сборки применяется отдельно.

## Что включено

`backend/` — Python/FastAPI, обработка аудио, история, справочник, пять технических карточек и тесты. `frontend/` — React/TypeScript и Tauri. `build/`, `installer/` — сборка и исходники установщика. `testing/` — открытые диагностические инструменты.

Здесь нет весов моделей, DLL, готового установщика, пользовательской SQLite, резюме, истории разговоров, записей звонков, токенов и локальных журналов. Единственная включённая SQLite — фиксированный реестр технических карточек `backend/answer_cards/verified-v2.db`; его хеш проверяется backend.

## Разработка и проверки

Нужны Windows, Python 3.12 и Node.js. Для native-сборки также нужны Rust, MSVC C++ Build Tools и WebView2. Модели и зависимости устанавливаются отдельно; установка может потребовать скачивания и места на диске.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-lock.txt
Push-Location backend
..\.venv\Scripts\python.exe -m pytest -q
Pop-Location

Push-Location frontend
npm ci
npm test
npm run build
Pop-Location
```

Скрипт [build/Build.ps1](build/Build.ps1) создаёт переносимую сборку и запускает проверки. Он может устанавливать зависимости в свою среду. Legacy-мастер `Setup.ps1` сохраняет прежние варианты моделей по умолчанию; не используйте его без проверки параметров, если хотите воспроизвести профиль Gemma выше. Веса не входят в этот репозиторий.

Профиль `settings.example.json` описывает текущие параметры, но не содержит абсолютных путей личной установки. После сборки укажите локальный ASR-путь и выберите ту же модель в настройках приложения. Подключения inference допускаются только к loopback; онлайн-справка в текущем профиле выключена.

## Результаты и ограничения

На последней версии backend прошли 285 тестов, один GPU-тест пропущен. На текущем интерфейсе прошли 35 тестов. Исполняемые файлы собирались и проверялись в рабочей установке. Это результаты предшествующей проверки соответствующих исходников; данный репозиторий не содержит готовых бинарников или обещания воспроизведения без подготовки среды.

Модель может допускать технические ошибки, даже с карточками. Проверки карточек и отдельных программ не являются сертификацией всех ответов человеком. Рост общего full_correct до 80–90% не доказан. Небольшие открытые проверки выбора формата ответа не заменяют независимый бенчмарк.

Ожидание 4 секунд — пауза определения конца речи; распознавание и генерация добавляют время. Существующий предел одного аудиофрагмента 15 секунд может завершить фрагмент раньше полной паузы. Гарантия ответа за 3 секунды не заявляется, особенно для длинного кода.

Поддерживается небольшой набор Markdown, а не весь CommonMark. Распознавание просьб о коде основано на правилах и инструкции модели; оно не покрывает любые возможные формулировки.
